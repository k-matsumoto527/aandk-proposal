# A and K さま ホームページ リニューアルご提案

株式会社 A and K さま（www.aandkcorp.com）のコーポレートサイト刷新にあたり、
**構成（間取り図）を決めていただくための資料**。デザインを決めるものではない。

公開URL: https://k-matsumoto527.github.io/aandk-proposal/

## 方針（ユーザーと決めたこと）

| 項目 | 決定 |
| --- | --- |
| 範囲 | **外国人材事業に絞る**（児童福祉はかみのてのサイトへ） |
| 目的 | **会社の信用づくり**（問い合わせ数より、まず信用されること） |
| 言語 | まずは日本語のみ（あとから足せる作りにする） |
| サーバー | **EWC側で引き取る**（https化のため。ドメインは継続利用） |

## 意匠は kaminote-proposal と共通

**CSSとスクリプト、外枠（濃紺の固定ヘッダー・目次・表紙・節の番号レール・
フッター）は `~/kaminote-proposal/src/design-kaminote.html` から流用している。**
EasyWebCraft の提案書はこの1つの型で揃える。かみのて側を直したらこちらにも
反映するか判断すること（いまは手でコピーしている）。

**文章は必要最低限にする**（ユーザー指示）。節は 00はじめに／01デザイン案／
02ページの構成／03ご確認いただきたいこと／04料金と進め方 の5つだけ。
**太字は「判断・行動をしてほしいところ」と「ご要望を反映した点」だけ**に使う
（かみのてで決めたルール。増やすと強調が機能しなくなる）。

## 編集のしかた

原本は `src/proposal-aandk.html`（Artifact用のHTML断片＝`<head>`を持たない）。
`build.py` が viewport・リセットCSS・OGP・noindex を被せて `index.html` を作る。

```bash
cd ~/aandk-proposal && python3 build.py
```

**生成物を直接編集しないこと。** 原本と生成物は必ず一緒にコミットする
（生成物だけ revert しても次のビルドで戻ってしまうため）。
